# Game assets

`fonts/garden_name_16.c` is a 16 px, 4 bpp Source Han Sans SC Normal subset containing the seven companion stage names. It was generated with `lv_font_conv` 1.5.3; the exact command is in the generated file header. The source OTF is bundled with LVGL 9.5.0 at `scripts/built_in_font/SourceHanSansSC-Normal.otf` and uses the SIL Open Font License 1.1.

# 游戏素材

`fonts/garden_name_16.c` 是 16 像素、4 bpp 的思源黑体简体字库子集，覆盖象芽七个成长阶段的中文名称。使用 `lv_font_conv` 1.5.3 生成，完整命令记录在生成文件头部。源 OTF 随 LVGL 9.5.0 提供，路径为 `scripts/built_in_font/SourceHanSansSC-Normal.otf`，许可为 SIL Open Font License 1.1。
